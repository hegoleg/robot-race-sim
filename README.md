# 🏎️ Line Robot Simulator (Инженерный симулятор подбора компоновки)

Профессиональный интерактивный симулятор для подбора **идеальной физической компоновки** и отладки **Arduino / C++ алгоритмов** спортивных роботов для соревнований «Гонки по линии» (Line Follower).

## ✨ Ключевые возможности

### 1. 💻 Настоящий код Arduino (C++)
- Поддержка синтаксиса и стандартных функций Arduino: `setup()`, `loop()`, `constrain()`, `map()`, `abs()`, `min()`, `max()`, `millis()`, `Serial.println()`.
- Библиотека сенсоров: `readLineBlack(sensorValues)` — возвращает взвешенное положение центра линии от `0` до `(N-1)*1000`.
- Управление моторами: `setMotors(left, right)` или `setMotorA()`, `setMotorB()` в диапазоне `-255 .. +255`.
- **Сохранение состояния глобальных переменных**: интегратор (`integral`) и предыдущая ошибка (`lastError`) сохраняются между итерациями `loop()`, как на реальном микроконтроллере (ESP32-S3 / STM32 / Arduino).
- Встроенные шаблоны:
  - *Спортивный PID (ESP32-S3 High-Speed)*
  - *Пропорциональный P-регулятор*
  - *PID + Интеллектуальный возврат на линию (Recovery)*

### 2. ⚙️ Инженерный подбор идеальной компоновки
- **Шасси и геометрия колес**:
  - **Длина базы (колея)**: $45$ – $140$ мм.
  - **Радиус колеса**: $10$ – $35$ мм (диаметр от 20 до 70 мм).
  - **Ширина профиля колеса**: $5$ – $25$ мм (влияет на площадь пятна контакта и боковой снос).
  - **Коэффициент сцепления шин (Grip)**: резина ($0.8$), силикон ($1.3$), липкий полиуретан ($1.6+$).
  - **Масса робота**: $50$ – $350$ г (учитывается момент инерции и центробежные силы в виражах).
- **Силовая установка и электроника**:
  - **Обороты двигателя (Motor RPM)**: $300$ – $3500$ об/мин (N20, Coreless, Pololu HP).
  - **Напряжение аккумулятора**: 1S LiPo ($3.7$ В), 2S LiPo ($7.4$ В), 3S LiPo ($11.1$ В), 4S LiPo ($14.8$ В).
  - **КПД драйвера**: расчет падения напряжения на ключах (TB6612FNG, A4950, MOSFET).
- **Сенсорная линейка (QTR)**:
  - Количество ИК-датчиков: $3$, $5$, $8$, $12$, $16$ шт.
  - Расстояние между датчиками (Pitch): $4$ – $22$ мм.
  - Вынос планки вперед (Overhang): $20$ – $120$ мм.
  - Высота подвеса над трассой: $1$ – $10$ мм (с затуханием контраста при отклонении от оптимума $3$–$5$ мм).

### 3. 🎮 Управление и запуск робота (Start / BOOT)
- **Физическая кнопка робота (BOOT / GPIO 0)**: интерактивная кнопка старта на арене симуляции с тактильной анимацией нажатия и светодиодным индикатором питания.
- **Кнопка запуска в шапке (Header Bar)**: всегда доступная крупная кнопка «▶ Запустить робота / ⏸ Пауза» со статусом готовности.
- **Кнопка запуска в редакторе кода**: мгновенный запуск робота сразу после изменения алгоритма.
- **Горячие клавиши**:
  - `Пробел` — старт / пауза заезда
  - `Ctrl + Enter` (в редакторе) — компиляция и запуск робота
  - `R` — сброс робота на стартовую позицию
- **Синтезатор звуков**: аудиоэффекты старта двигателя, щелчка тактовой кнопки, паузы и победных фанфар при рекорде круга (Web Audio API).

### 4. ⏱️ Телеметрия и замер времени круга
- **Засечка круга**: старт/финиш створ с фиксацией лучшего времени круга (**Best Lap**) и текущего круга.
- **Спидометр в реальном времени**: скорость в **км/ч** и **м/с**.
- **Детектор заноса (Tire Slip)**: физическая модель центробежного сноса шин на предельных скоростях.
- **Траекторный след (Ghost Trail)**: визуализация траектории движения робота для выявления рыскания и раскачки.
- **Интерактивность**: кликните в любую точку трассы для перемещения робота, потяните мышь для задания направления старта.

## 🏎️ Пресеты компоновок

1. **⚡ Pro Racing Chassis (1500 RPM)**:
   - Боевая соревновательная компоновка: ESP32-S3, 2S LiPo (7.4V), TB6612FNG, N20 1500 RPM, линейка QTR-8RC (8 датчиков), масса 120 г, колеса 32 мм.
2. **🏆 Скоростной Монстр (3000 RPM Coreless)**:
   - Бесколлекторные моторы 3000 RPM, 3S LiPo (11.1V), 12 датчиков, силиконовые слики 16 мм, масса 95 г.
3. **🔰 Надежный Учебный (600 RPM N20)**:
   - Базовая модель: 1S LiPo (3.7V), 600 RPM, 5 датчиков, масса 150 г.
4. **🧱 Lego / Колесный Тандем (350 RPM)**:
   - Тяжелое шасси 280 г с большими колесами 56 мм.

## 🚀 Сборка и запуск

### Запуск в режиме разработки:
```bash
npm install
npm run dev
```

### Сборка Windows установщика (.exe):
```bash
npm run build
```
