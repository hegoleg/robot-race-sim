<p align="center">
  <img src="assets/ui_preview.jpg" alt="Интерфейс симулятора Line Robot Simulator" width="100%" />

> **Минималистичный и эргономичный интерфейс**:
> - 📝 **Слева:** Встроенный редактор кода Arduino (C++) с подсветкой синтаксиса, номерами строк и горячей компиляцией (`Ctrl + Enter`).
> - 🏁 **По центру:** Холст симуляции 60 FPS с честной физикой заноса, лучами ИК-оптопар, следом траектории и единой кнопкой запуска **[ ▶ Запустить робота ]**.
> - 📊 **Сверху:** Вынесенная полоса телеметрии (скорость, время круга, статус заезда, показания сенсоров) — больше ничего не перекрывает обзор трассы!
> - ⚙️ **Справа:** Инженерная панель калибровки физики (масса, RPM, колея, диаметр колес, вынос сенсорной линейки, напряжение LiPo).

## ✨ Ключевые возможности

### 🔌 Умный анализатор распиновки и загрузка любого скетча (.ino / .cpp)
* **Загрузка и Drag & Drop**: перетащите любой файл `.ino`, `.cpp` или `.h` прямо в окно редактора или используйте кнопку **«Загрузить»**.
* **Автоматическое определение драйвера моторов**:
  - **TB6612FNG**: распознавание `PWMA, AIN1, AIN2` и `PWMB, BIN1, BIN2, STBY`.
  - **L298N / L293D**: распознавание `ENA, IN1, IN2` и `ENB, IN3, IN4`.
  - **DRV8833 / MX1508**: 2-ШИМ режим моторов.
  - **PWM + DIR**: раздельный канал скорости и направления.
  - **ESP32 LEDC**: аппаратный ШИМ через `ledcWrite()`.
  - **Вызовы функций**: `setMotors()`, `motors()`, `drive()`, `motorLeft()`, `motorRight()`.
* **Автоопределение датчиков линии**:
  - Распознает массивы пинов (`int sensorPins[] = {A0, A1, A2, A3, A4}`), отдельные `#define S1..S8`, вызовы `analogRead(A0..A15)` или `digitalRead()`.
  - **Кнопка автосинхронизации**: если в коде 5 датчиков, а на шасси 8 — симулятор предложит кнопку `[⚡ Синхронизировать (5 шт)]`, чтобы мгновенно подогнать модель робота под ваш код!
* **Эмуляция библиотеки Pololu `QTRSensors`**:
  - Поддержка классов `QTRSensors`, `qtr.readLineBlack()`, `qtr.readLineWhite()`, `qtr.calibrate()`, `qtr.setSensorPins()`.

### 1. 💻 Настоящий код Arduino (C++) без ограничений
* **Полная виртуальная таблица GPIO**: функции `digitalWrite()`, `analogWrite()`, `digitalRead()`, `analogRead()`, `pinMode()` работают в точности как на железной плате.
* **Синтаксис 1-в-1 с контроллерами**: поддержка функций `setup()`, `loop()`, `pinMode()`, `analogRead()`, `millis()`, `constrain()`, `map()`, `Serial.println()`.
* **Управление моторами**: функция `setMotors(left, right)` или `setMotorA()`, `setMotorB()` в диапазоне от `-255` до `+255`, а также через аппаратный ШИМ.
* **Чтение сенсоров**: функция `readLineBlack(sensorValues)` вычисляет средневзвешенное положение центра линии от `0` до `(N-1)*1000`.
* **Сохранение памяти между итерациями**: глобальные переменные (`lastError`, `integral`, таймеры) сохраняют состояние от тика к тику, позволяя точно отлаживать дифференциальную ($K_d$) и интегральную ($K_i$) составляющие ПИД-регулятора.

```cpp
// Пример спортивного ПИД-регулятора на C++
#define BASE_SPEED 180
#define MAX_SPEED 255

float Kp = 0.085;
float Kd = 1.45;
int lastError = 0;

void loop() {
  int sensorValues[8];
  int position = readLineBlack(sensorValues);
  int error = position - 3500; // Центр для 8 датчиков (0..7000)

  int motorSpeed = Kp * error + Kd * (error - lastError);
  lastError = error;

  setMotors(BASE_SPEED + motorSpeed, BASE_SPEED - motorSpeed);
}
```

## 🛠️ Аппаратное соответствие и физическая модель

<p align="center">
  <img src="assets/robot_hardware.jpg" alt="Аппаратная компоновка спортивного робота" width="100%" />
</p>

Симулятор учитывает реальные механические и электрические параметры спортивных шасси соревновательного класса **Line Follower / RoboTrace**:

| Подсистема | Параметры в симуляторе | Влияние на физику заезда |
|:---|:---|:---|
| **Колесная база и геометрия** | Колея ($45$ – $140$ мм), диаметр ($20$ – $70$ мм), ширина ($5$ – $25$ мм) | Маневренность, радиус разворота, устойчивость к крену |
| **Сцепление шин (Grip)** | Коэффициент трения $\mu$ ($0.8$ – $1.8+$): резина, силикон, полиуретан | Предельная скорость прохождения поворотов без вылета с трассы |
| **Силовая установка** | Обороты $300$ – $3500$ RPM, напряжение 1S–4S LiPo ($3.7$ – $14.8$ В) | Время разгона, линейная скорость на прямых, тормозной момент |
| **Сенсорная планка** | $3, 5, 8, 12, 16$ ИК-датчиков, вынос вперед ($20$ – $120$ мм), шаг ($4$ – $22$ мм) | Упреждение траектории (lookahead) и точность позиционирования |
| **Масса и инерция** | Вес от $50$ до $350$ г с расчетом момента инерции $J$ | Боковой снос на входе в шпильки и шиканы |

## 🏁 Доступные гоночные трассы

1. **🔄 Классический овал (Oval)** — базовая калибровка пропорционального коэффициента $K_p$ и максимальной скорости.
2. **〰️ Слалом (Slalom)** — непрерывная связка плавных S-образных виражей с переменным радиусом кривизны.
3. **📐 Прямые углы 90° (Sharp 90°)** — стресс-тест алгоритма разворота на месте и алгоритма поиска потерянной линии.
4. **🪃 Шпилька 180° с шиканой (Hairpin)** — длинная скоростная прямая с резким торможением в вираж 180°.
5. **♾️ Восьмерка (Infinity)** — трасса с пересечением траекторий и разворотом направления крена.

## 🎮 Управление и горячие клавиши

* **[ ▶ Запустить робота ] / [ ⏸ Пауза ]** — единая удобная кнопка управления заездом в тулбаре над ареной.
* `Пробел` — глобальный старт / пауза в любой момент времени.
* `R` — мгновенный сброс робота на стартовую позицию и сброс таймера круга.
* `Ctrl + Enter` — быстрая компиляция кода в редакторе с сохранением параметров.
* **Клик / Перетаскивание мыши** — свободная установка робота в любую точку трека с заданием угла старта.

## 🚀 Быстрый старт

### Способ 1: Готовый Windows файл (Без установки Node.js)
1. Скачайте портативную версию симулятора или запустите файл:
   ```cmd
   Запустить_Симулятор.bat
   ```
2. Или запустите готовый бинарник из папки `release\win-unpacked\Line Robot Simulator.exe`.

### Способ 2: Запуск из исходного кода
Требуется [Node.js](https://nodejs.org/) (версии 18 или новее):

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/hegoleg/robot-race-sim.git
cd robot-race-sim

# 2. Установите зависимости
npm install

# 3. Запустите симулятор в браузере
npm run dev

# 4. Или запустите в режиме настольного приложения Electron
npm run electron:dev
```

### Сборка собственного .exe установщика:
```bash
npm run build
```
Готовый инсталлятор будет сохранен в папке `release/`.
